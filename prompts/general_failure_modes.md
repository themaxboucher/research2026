# Grammatical error

The comment contains a grammar or spelling mistake.

Example: `# Retrys the request if it fail`

# Wrong style

The comment is not written in the style of a code comment. For example, it narrates a change or is written in the past or future tense.

Example: `# Changed this to use a set for faster lookups`

# Verbose

The comment uses more words than it needs to, or big words where simpler language would be just as precise. The comment is harder to read as a result.

Example: `# This line of code is responsible for performing the incrementation of the retry counter` (instead of `# Increment the retry counter`)
